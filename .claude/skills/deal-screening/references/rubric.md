# 初期検討ルーブリック（青塗り12項目）

出所: `(TE版)投資検討_テンプレ_2607ver` → `投資条件` タブ、塗り色 `#CFE2F3` の行。
評価は6値: `◯` / `△〜◯` / `△` / `×〜△` / `×` / `－`（情報不足・判定不能）
スコア: ◯=2.0 / △〜◯=1.5 / △=1.0 / ×〜△=0.5 / ×=0 / `－`=分母から除外

**Must項目（1-1・1-3・2・5）に `×` が1つでも付いたら総合C（見送り）。**

1-2（1件あたりの資金負担）はMustではない。買収予算に1件あたりの上限を置いていないため、
資金規模だけで案件を落とさない。代わりに1-3（非キャッシュ性資産の重さ）をMustに置く。
**アセットは軽いほうがよい**という方針を、ここで効かせる。

## 数値サマリー（管理表転記用の4項目）

○△×は付けない。ソーシング管理表 hot案件シートへ転記するための数字。

| 項目 | 定義 | 出所 |
|---|---|---|
| 譲渡価格 | 希望株式価値。条件付き（進行期の純資産積み上げ分 等）なら `price_note` に明記 | 概要書の希望価格 |
| EBITDA | 直近期の**実態**EBITDA（役員報酬・私的経費等の調整後） | 概要書の実態収益＋減価償却費 |
| EV/EBITDAマルチプル | `①EV/EBITDA`（TE定義。EV＝譲渡価格−実質NetCash） | No.5 と同じ算式 |
| 売上 | 直近期の売上高 | 損益計算書 |

**マルチプルは2種類出す。** TE定義（運転資金を調整した実質NetCashベース）を主とし、
仲介が提示してくる簿価NetDebtベースも参考で併記する。運転資金が重い業種では
両者が倍以上開く（左官工事の実例：TE定義19.4倍／簿価ベース11.1倍）。

**売上レンジ 300〜3,000百万円**（投資条件友井タブ No.20「売上30億円超・3億円未満は
対象外」／仲介向け資料P10「売上目安3〜30億円」）の範囲内かを添える。青塗り外の
項目なので評価には算入しない。

## No.1 投資ポリシーとの合致（3基準）

### 1-1 業種ターゲットとの整合 ★Must（定性）

| 評価 | 条件 |
|---|---|
| ◯ | 重点業種①シニア／②AI・DXで伸ばせる業種／③エネルギー関連に直接該当 |
| △〜◯ | `追加候補業種` タブ A群（狙える逆張り）に該当 |
| △ | B群（化けるが罠が多い）に該当し、罠を回避できる形になっている |
| ×〜△ | B群だが罠そのもの（スポット運送／常駐主体の警備／一般旅行 等） |
| × | NG業種7カテゴリのいずれか、または C群（タクシー等） |

NG7: ❶飲食・嗜好流行依存 ❷法的制度的に承継困難（医療法人・社福・学校法人・士業・農業法人）
❸重資産（不動産開発・採掘・鉄道・公共インフラ）❹職人技能依存（一次産業・伝統工芸・職人依存建設）
❺AI代替リスクIT（SIer・SES・受託開発）❻大型総合小売（百貨店・GMS）❼社会的懸念（風俗・水商売・消金・パチンコ）

### 1-2 1件あたりの資金負担（定量）

買収予算は**グループ全体で25億円**。これはTEが出す自己資金の総枠で、買収借入はこの上に
乗せられる。1件あたりの金額上限は置いていないので、**枠に対してその1件がどれだけ重いか**で見る。

```
TE自己資金拠出額 ＝ ネット所要資金 − 買収借入
```

ネット所要資金の積み上げは `references/acquisition-funding.md`。株式価値だけでなく、
譲渡時に返済する借入と、対象会社から回収できる余剰現預金まで含めた数字を使う。

| 評価 | 枠25億円に占める割合 | 金額 |
|---|---|---|
| ◯ | 20%以下 | 5.0億円以下 |
| △〜◯ | 20%超 30%以下 | 5.0〜7.5億円 |
| △ | 30%超 40%以下 | 7.5〜10.0億円 |
| ×〜△ | 40%超 50%以下 | 10.0〜12.5億円 |
| × | 50%超 | 12.5億円超 |

**1件で枠の半分を超えたら ×。** 分散が効かなくなる水準に線を引いている。
ただし **Must ではない**ので、× が付いても他項目で挽回でき、代表判断の余地が残る。

買収借入が未定のときは、ネット所要資金そのものを上限として評価する。借入はこの額を
減らす方向にしか働かないので、上限で付けた評価より悪くなることはない。

現預金と有利子負債が分からず所要資金を積み上げられない場合は `株式価値＋承継コスト`
で代用する。その場合は代用した旨を根拠に明記する。

**借入が実現できるかは No.6（投資リターンが合うか）で見る項目**であり、
No.1-2 はTEが自己資金でいくら出すかだけを問う。

### 1-3 非キャッシュ性資産が重くないか ★Must（定量）

`重さ = （有形固定資産 + 棚卸資産）÷ 実態EBITDA`

| 評価 | 倍率 |
|---|---|
| ◯ | 2.0倍以下 |
| △〜◯ | 2.0倍超 3.0倍以下 |
| △ | 3.0倍超 5.0倍以下 |
| ×〜△ | 5.0倍超 8.0倍以下 |
| × | 8.0倍超、または装置産業・不動産主体で更新投資が読めない |

**この項目がMustなのは、アセットの軽さが買収予算そのものより効くため。** 重資産の案件は
取得後も更新投資が続き、25億円の枠を1件で食い続ける。8.0倍超は他項目で挽回しない。

## No.2 安定黒字か ★Must（定量）

基準: 実態EBITDAが3期連続黒字か

| 評価 | 条件 |
|---|---|
| ◯ | 3期連続黒字かつ増加基調（直近が3期中最大） |
| △〜◯ | 3期連続黒字で横ばい（直近が最大値の90%以上） |
| △ | 3期連続黒字だが直近が前期比▲20%以上、または補助金・特需を除くと薄い |
| ×〜△ | 3期中1期が赤字 |
| × | 2期以上赤字、または実態調整後に直近期が赤字 |

「実態」EBITDAで見る。役員報酬・地代・私的経費の調整前の数字しか無い場合は
調整前と明記し、`△〜◯` を上限とする。

**業歴が3期に足りない案件**（設立して2年以内など）は `－` にしない。情報が
不足しているのではなく、要件を構造的に満たせないことが確定しているからである。

| 業歴 | 評価 |
|---|---|
| 2期あり・両期黒字 | `×〜△`（3期連続黒字の要件は満たせない。業歴の短さ自体が本項目のリスク） |
| 2期あり・1期以上赤字 | `×` |
| 1期のみ | `×` |

No.2 は「3年の継続性」を見る項目なので、2期分の黒字では代替できない。

## No.3 付加価値は高いか（定量）

基準: 3期連続で粗利率30%以上か

| 評価 | 条件 |
|---|---|
| ◯ | 3期すべて30%以上 |
| △〜◯ | 3期平均30%以上（1期だけ30%を僅かに下回る） |
| △ | 3期平均25%以上30%未満 |
| ×〜△ | 3期平均20%以上25%未満 |
| × | 3期平均20%未満、または3期で5pt以上の低下トレンド |

**業歴が3期に足りない場合**は、No.2 と違って水準そのものを見る項目なので
2期でも材料になる。ただし1期分の確認が取れないぶん上限を設ける。

| 業歴 | 上限 |
|---|---|
| 2期あり | `△〜◯` |
| 1期のみ | `△` |

上限の範囲内で、平均値に応じて通常の閾値を当てる（平均25%未満なら `△`、
20%未満なら `×` のまま）。

## No.4 永続性は高いか（定性）

基準: 市場は10年後も残り続けるか

| 評価 | 条件 |
|---|---|
| ◯ | 人口動態・法定需要が需要を押し上げる（シニア、電気保安、設備保守 等） |
| △〜◯ | 需要は残るが競争構造が変わる見込み |
| △ | 横ばい。代替技術の影響が読めない |
| ×〜△ | 縮小基調、または政策・報酬改定への依存が大きい |
| × | 10年で構造的に消える（AI代替、明確な斜陽） |

## No.5 価格は割高ではないか ★Must（定量）

```
実質NetCash = 簿価NetCash − 平均必要運転資金   （マイナスなら実質NetDebt）
EV          = 株式価値 − 実質NetCash
①価格評価   = EV ÷ 実態EBITDA
②実質価格評価 = (EV + 承継コスト) ÷ 実態EBITDA     ← 判定はこちらを採用
承継コスト   = 仲介手数料 + DD費用等
```

| 評価 | ②の倍率 |
|---|---|
| ◯ | 5.0倍以下 |
| △〜◯ | 5.0倍超 6.0倍以下 |
| △ | 6.0倍超 7.0倍以下 |
| ×〜△ | 7.0倍超 8.0倍以下 |
| × | 8.0倍超 |

出力には①②の両方を書く。閾値の根拠は SKILL.md の「EV/EBITDA の閾値について」。

## No.11 特定取引先に依存していないか（定量）

顧客側は上位1社売上比率、発注先側は上位1社仕入比率。**悪い方を採用。**

| 評価 | 上位1社比率 |
|---|---|
| ◯ | 10%未満 |
| △〜◯ | 10%以上 20%未満 |
| △ | 20%以上 30%未満（依存度を下げる余地がある） |
| ×〜△ | 30%以上 50%未満 |
| × | 50%以上、または代替不能な単一発注先に依存 |

**境界値は悪い側に入る。** ちょうど10%／20%／30%／50%はそれぞれ `△〜◯`／`△`／
`×〜△`／`×`。他の定量項目（1-2・1-3・5）は「○○以下」なので境界値は良い側に入り、
この項目だけ扱いが逆になる。

## 総合判定

```
得点   = Σ（各項目のスコア）           ※ － は加算も分母もしない
判定済 = ６値のうち － 以外が付いた項目数
達成率 = 得点 ÷ (判定済 × 2)
```

| 判定 | 条件 |
|---|---|
| **C：見送り** | Must（1-1・1-3・2・5）に `×` が1つ以上、または全体で `×` が2つ以上 |
| **A：進める（トップ面談・基本合意検討へ）** | `×` ゼロ、かつ達成率75%以上 |
| **B：追加情報を取得して再判定** | 上記以外 |

判定済が6項目未満のときは、達成率に関わらず B とし「概要書の情報量が不足」と書く。

案件管理表ではこの判定が `AI総合判定` 列（自動計算）に入る。
隣の `友井判定` 列は友井さんが手でA／B／Cを置く欄で、ルーブリックの外にある
論点（業種の毛色、代表判断、交渉余地、仲介との関係）をここで上書きする。
両者が食い違う行はシート上で紫になるので、食い違いの理由は初期検討メモに残す。
この表の12項目の◯／△／× は案件管理タブの4〜6行目にも短縮して敷いてあり、
閾値を動かすときは rubric.md・判定基準タブ・案件管理タブの基準帯の3つを直す。
