# タスク投げ込み — チャットに書くだけでシートに転記される仕組み

「everyタスク管理表」をそのまま主役に残したまま、**思いついた瞬間にスマホやチャットへ投げるだけ**で、
AI が「①誰から誰に ②期限・やってほしいこと」を読み取り、**担当者のタブへ自動で転記**します。

自分のメモに書いて、あとからシートへ書き写す、という二度手間をなくすのが目的です。

```
  LINE / Google Chat に投稿
  スマホの投げ込みページ（音声入力OK）        ┐
  iOSショートカット・他アプリ（JSON POST）    ┘
              ↓
      Claude が日本語を読み取る
      （誰から / 誰へ / 期限 / やること / 案件 / 急ぎか）
              ↓
   ┌──────────────┴──────────────┐
   ↓                              ↓
「受信箱」タブ                担当者の個人タブ
（原文つきで全件保存）        （既存の表の末尾に追記）
              ↓
      その場で結果が返信される
```

投稿例：

> 友井さんへ。今月中までに、弟子屈で使えそうな補助金を全部洗い出して欲しい。
> 特に新しい車を買うための助成金や補助金は急いで探して欲しい。

返信例：

```
✅ 2件を登録しました

① 友井さん
　弟子屈で使える補助金の洗い出し
　期限 8/31（今月中までに）
　案件 補助金・助成金
　→ 友井 タブ 24行目

② 友井さん【急ぎ】
　新車購入向けの助成金・補助金の調査
　期限 8/31
　→ 友井 タブ 25行目
```

---

## できること

| | 内容 |
| --- | --- |
| **宛先の自動判別** | 「友井さんへ」「トモイ」「友井大勢」「@友井」「To 友井」いずれでも本人に届きます |
| **相対日付の変換** | 「今月中」「来週」「月末」「9/4」→ 実日付に直してから書き込みます |
| **1投稿の複数タスク分割** | 「◯◯して。特に△△は急ぎで」→ 2件に分けて登録します |
| **急ぎの判定** | 「至急」「急いで」「特に」などがあれば詳細に【急ぎ】を付けます |
| **案件名の引き継ぎ** | 既存タブに入っている案件名（nuppukotte／M&A／交流会 等）を優先して使います |
| **音声入力** | スマホの投げ込みページで話して入力。キーボードのマイクでも書けます |
| **判別できないときは保留** | 担当者が分からない投稿を勝手に誰かへ割り当てず、「受信箱」に要確認で残します |
| **原文の保存** | 「受信箱」タブに投稿の原文がそのまま残るので、あとから見返せます |

**既存のタブは壊しません。** 見出し行（「タスク」「期限」）を自動で探し、表の末尾に1行足すだけです。
共香タブのように表が B 列から始まっていても、結合セルが混じっていても正しい位置に書きます。

## セットアップ

所要 20〜30分。**手順1〜5だけで、スマホからの投げ込みが使えるようになります。**
LINE / Google Chat 連携（手順6・7）は、必要になってからで構いません。

### 1. スクリプトをスプレッドシートに入れる

1. 「everyタスク管理表」を開く → メニュー **拡張機能 → Apps Script**
2. 左の「ファイル」で、このフォルダの中身と同じ名前・同じ内容のファイルを作る

   | 作るファイル | 種類 | 中身 |
   | --- | --- | --- |
   | `Config` | スクリプト | `Config.gs` |
   | `Parse` | スクリプト | `Parse.gs` |
   | `SheetIO` | スクリプト | `SheetIO.gs` |
   | `WebApp` | スクリプト | `WebApp.gs` |
   | `Chatbots` | スクリプト | `Chatbots.gs` |
   | `Setup` | スクリプト | `Setup.gs` |
   | `Capture` | **HTML** | `Capture.html` |

   最初からある `コード.gs` は削除して構いません。
3. 左下の歯車（プロジェクトの設定）で **「appsscript.json マニフェスト ファイルをエディタで表示する」にチェック** を入れ、
   `appsscript.json` の中身をこのフォルダの `appsscript.json` に置き換える
4. 保存（Ctrl / ⌘ + S）

> **コマンドでまとめて入れたい場合**は [clasp](https://github.com/google/clasp) が使えます。
> `npm i -g @google/clasp && clasp login` のあと、このフォルダで
> `clasp clone <スクリプトID>` → ファイルを上書き → `clasp push`。
> スクリプトIDは Apps Script の「プロジェクトの設定」に表示されています。

### 2. 初期セットアップを実行

1. スプレッドシートを**開き直す**（メニューに「タスク投げ込み」が出ます）
2. **タスク投げ込み → ① 初期セットアップ**
   - 初回は権限の確認が出ます。「詳細」→「(プロジェクト名) に移動」→「許可」
   - 「受信箱」タブと「設定」タブが作られます
3. **「設定」タブ**を開き、メンバーの行を確認します

   | キー | 氏名 | タブ名 | 別名（／区切り） | LINE userId | メールアドレス |
   | --- | --- | --- | --- | --- | --- |
   | 友井 | 友井大勢 | `友井 ` | 友井大勢／ともい／トモイ | （手順6で記入） | （手順7で記入） |

   - **タブ名は実際のタブ名と完全に一致させてください**（「友井 」のように末尾に空白が入っている場合はそのまま）
   - タブが存在しないメンバー（竹田さん）は、初回の転記時に「原本」タブから自動で作られます
4. 編集したら **タスク投げ込み → 設定タブの内容を保存**

### 3. Claude APIキーを登録

1. [console.anthropic.com](https://console.anthropic.com/) でAPIキー（`sk-ant-…`）を発行
2. **タスク投げ込み → ② Claude APIキーを設定…** に貼り付け
   （シートには保存されず、スクリプトプロパティに入ります）
3. **タスク投げ込み → 解析テスト** で読み取り結果を確認（シートには書き込まれません）

> APIキーを登録しなくても、正規表現ベースの簡易パーサで動きます。ただし
> 案件名の推測・複数タスクへの分割・複雑な日本語の解釈はできません。

### 4. ウェブアプリとして公開

1. Apps Script エディタ右上の **デプロイ → 新しいデプロイ**
2. 歯車 → **ウェブアプリ** を選択
3. 設定
   - 説明：`タスク投げ込み`
   - **次のユーザーとして実行：自分**
   - **アクセスできるユーザー：全員**（LINE や Chat から呼ぶために必要）
4. **デプロイ** → 表示された URL を控える
5. スプレッドシートに戻り **タスク投げ込み → スマホ用URL・Webhook URLを表示**
   → 合言葉（`?k=…`）付きの URL が表示されます。**以降はこの URL を使います。**

> コードを直したあとは、**デプロイ → デプロイを管理 → 鉛筆マーク → バージョン「新バージョン」→ デプロイ**
> で更新してください。URL は変わりません。

### 5. スマホのホーム画面に追加

手順4の URL をスマホで開き、

- **iPhone (Safari)**：共有ボタン →「ホーム画面に追加」
- **Android (Chrome)**：メニュー →「ホーム画面に追加」

これでアプリのように1タップで開けます。

---

### 6.（任意）LINE から投げられるようにする

1. [LINE Developers](https://developers.line.biz/console/) で **Messaging API チャネル**を作成
2. **Messaging API 設定** タブで
   - **チャネルアクセストークン（長期）** を発行してコピー
   - **Webhook URL** に手順4の URL（`?k=…` 付き）を貼り、**Webhookの利用を ON**
   - **応答メッセージを OFF**（自動応答が邪魔をするため）
   - グループで使うなら **「グループトーク・複数人トークへの参加を許可する」を ON**
3. Apps Script エディタ → **プロジェクトの設定 → スクリプト プロパティ** で追加

   | プロパティ | 値 |
   | --- | --- |
   | `LINE_CHANNEL_ACCESS_TOKEN` | 手順2でコピーしたトークン |

4. **メンバー全員がボットを友だち追加**し、それぞれ **「id」とだけ送信**
   → 自分の userId が返ってくるので、「設定」タブの LINE userId 欄に貼り付け
   → **タスク投げ込み → 設定タブの内容を保存**

   これで「誰が投げたか（依頼者）」が自動で入るようになります。

### 7.（任意）Google Chat から投げられるようにする

1. [Google Cloud Console](https://console.cloud.google.com/) で **Google Chat API** を有効化
2. Chat API の **構成** タブで
   - アプリ名 `タスク投げ込み` / 説明を記入
   - 機能：**1:1メッセージを受信** と **スペースとグループの会話に参加** を有効
   - 接続設定：**アプリの URL** に手順4の URL（`?k=…` 付き）
   - 公開範囲：自組織の必要なユーザー / グループ
3. 「設定」タブの **メールアドレス**欄に各メンバーの Google アカウントを記入して保存
   → 投稿者が依頼者として自動で入ります

### 8.（任意）iOSショートカット等から投げる

手順4の URL に JSON を POST するだけです。

```
POST <ウェブアプリURL>?k=<合言葉>
Content-Type: application/json

{"text": "友井さんへ 今月中に補助金を洗い出して", "from": "智春"}
```

## 書き方のコツ

- **宛先を先頭に**：`友井さんへ` `@友井` `To 友井` のいずれか。これが一番確実です。
- 期限はふつうの言葉でOK：`今月中` `来週` `月末まで` `9/4` `3日後`
- 急ぎは `至急` `急いで` `特に` などを入れると【急ぎ】が付きます
- 1回の投稿に複数の依頼を書いても、AI が分けて登録します
- 宛先を書かなかった投稿は、**勝手に誰かへ割り当てず**「受信箱」に要確認で残ります

## 書き込まれる場所

### 「受信箱」タブ（全件・原文つき）

| 列 | 内容 |
| --- | --- |
| ID / 受信日時 / 経路 | いつ・どこから来たか（LINE / GoogleChat / web / api） |
| 依頼者 / 担当者 | 誰から誰へ |
| プロジェクト / タスク / タスク詳細 / 期限 / 期限(原文) / 優先度 | 読み取った内容 |
| 状況 / 転記先 | `転記済`＋転記先のタブと行、または `要確認` |
| 解析エンジン | どのモデルで読み取ったか |
| **元メッセージ** | **投稿の原文そのまま** |

読み取りを間違えたときは、このタブを見れば原文が残っているので直せます。

### 個人タブ

既存の表の**末尾に1行だけ**足します。書き込む列は見出しから自動判定します。

| 列 | 入るもの |
| --- | --- |
| プロジェクト | 案件名（既存の案件名を優先） |
| タスク | タスク名 |
| タスク詳細 | `【急ぎ】（智春さん依頼） 補足…` |
| 期限 | 日付。日付にできない表現は文字のまま |
| 状況 | **空のまま**（既存シートの「空＝未着手」の慣習に合わせています） |

「設定」タブの **個人タブへ転記する** を `false` にすると、受信箱に貯めるだけになります。

## セキュリティ（必ず読んでください）

- **URL の `?k=…` が合言葉です。この URL を知っている人は誰でも書き込めます。**
  チーム内だけで共有し、SNS や公開の場に貼らないでください。
- **Apps Script は受信ヘッダーを読めないため、LINE の署名検証（X-Line-Signature）は実装できません。**
  代わりに URL の合言葉で認証しています。より厳密にしたい場合は、
  Cloud Functions など署名検証できる場所に受け口を置き、そこから Apps Script を呼ぶ構成にしてください。
- 合言葉を変えたいときは、スクリプトプロパティの `CAPTURE_TOKEN` を書き換えます（LINE / Chat 側の URL も更新）。
- APIキーとLINEトークンはスクリプトプロパティに入り、シートには残りません。
  ただし**スクリプトの編集権限がある人は閲覧できます**。編集権限は必要な人だけに。

## 費用

| | |
| --- | --- |
| Apps Script / スプレッドシート | 無料 |
| LINE Messaging API | 無料枠内（返信は応答メッセージ扱い） |
| Claude API | **1件あたり およそ3円**（`claude-opus-5`・文章量による） |

月に30件投げても100円程度です。安く済ませたい場合は、スクリプトプロパティ
`CLAUDE_MODEL` に `claude-sonnet-5` を入れると 1/3 程度になります。

読み取り精度を上げたいときは `CLAUDE_EFFORT` に `medium` / `high` を設定します。
既定が `low` なのは、Apps Script の外部リクエストが**約60秒で打ち切られる**ためです
（高い effort だと長文で時間切れになることがあります）。

## 設定できる項目（スクリプト プロパティ）

| 名前 | 既定 | 説明 |
| --- | --- | --- |
| `ANTHROPIC_API_KEY` | （空） | Claude APIキー。未設定なら簡易パーサで動作 |
| `CLAUDE_MODEL` | `claude-opus-5` | 使うモデル |
| `CLAUDE_EFFORT` | `low` | `low` / `medium` / `high` |
| `CAPTURE_TOKEN` | 自動生成 | URL の合言葉 |
| `LINE_CHANNEL_ACCESS_TOKEN` | （空） | LINE 返信用 |
| `WRITE_TO_PERSON_SHEET` | `true` | `false` で受信箱のみに保存 |
| `MEMBERS` | （自動） | 「設定」タブから保存される名簿。直接編集は不要 |
| `SPREADSHEET_ID` | （空） | 別のシートを対象にする場合のみ |

### 動作確認

コードを直したら、手元で流して壊れていないか確認できます。

```
node task-inbox/test/run.js
```

Apps Script をモックして動かすため、**ネットワークにも実際のスプレッドシートにも触りません**。
名前の表記ゆれ、日本語の期限表現、共香タブのような1列ずれレイアウト、結合セルの回避、
受信箱への記録までを確認します（Claude API は呼びません）。

## うまく動かないとき

| 症状 | 見るところ |
| --- | --- |
| メニューが出ない | スプレッドシートを開き直す。Apps Script に `Setup.gs` があるか確認 |
| LINE が無反応 | ①Webhook URL に `?k=…` が付いているか ②Webhookの利用がON ③応答メッセージがOFF ④`LINE_CHANNEL_ACCESS_TOKEN` を登録したか |
| LINE の「検証」が失敗する | デプロイのアクセス設定が**「全員」**になっているか確認。コード修正後に**新バージョンでデプロイし直した**か確認 |
| 転記されず受信箱に「要確認」だけ残る | 担当者を判別できていません。「◯◯さんへ」を先頭に付ける／「設定」タブの別名を増やす |
| 「見出し行が見つかりません」 | 対象タブに「タスク」「期限」という見出しセルがあるか確認（上から12行以内） |
| 期限がずれる | `appsscript.json` の `timeZone` が `Asia/Tokyo` か確認 |
| AI解析が効いていない | 受信箱の「解析エンジン」列を見る。`rule` ならAPIキー未設定かAPI失敗。Apps Script の「実行数」でログを確認 |
| 応答が遅い / 時々失敗する | `CLAUDE_EFFORT` を `low` に。それでも遅ければ `CLAUDE_MODEL` を `claude-sonnet-5` に |

## 既存の pms アプリとの関係

このリポジトリの [`pms/`](../pms/) は Firebase を保存先にしたチーム用ボードアプリです。
こちらの `task-inbox/` は**スプレッドシートを保存先のまま使う**別系統の仕組みで、両者は独立しています。
スプレッドシートを正本にしたい場合は `task-inbox/` を、ガントチャートや進捗率で管理したい場合は `pms/` をお使いください。
