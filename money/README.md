# マネーノート（ふたりで使う資金管理アプリ）

毎月の収支・遊びのお金・ギャンブルの資金を、**ふたりで1つの帳簿**に付けて管理するスマホ向けアプリです。
明細は「だれの」で分かれ、画面上部で **ふたり / わたし / 相手** を切り替えて、それぞれの給料に対していくら使えたかを見られます。
ホーム画面に追加すればアプリのように起動でき（PWA・オフライン対応）、**共有コード**で同じ帳簿をリアルタイムに共有します。

- 公開URL（GitHub Pages）: `https://ttomoi-afk.github.io/desktop-tutorial/money/`
- ビルド不要の静的アプリ（HTML / CSS / Vanilla JS のみ）。`pms/` と同じ作り（Firebase Realtime Database で共有）

## できること

| 画面 | 内容 |
| --- | --- |
| **今月** | その月の **収支**（収入・支出・差額）、**ふたりの今月**（それぞれの「使えるお金の残り」を並べて比較）、**給料の使いみち**（給料のうち 生活 / 遊び / ギャンブル にいくら使い、いくら残ったか）、**予算の残り**（生活・遊び・ギャンブルの3枠）、最近の明細 |
| **履歴** | 6か月の収入 vs 支出グラフ、月の明細一覧（種類で絞り込み・タップで編集）、カテゴリ別の内訳 |
| **ギャンブル** | 月の **資金枠と残り資金**、投入 / 払戻 / 損益 / 回収率 / 勝率 / 回数、**累積損益の推移**、**種目別**（ボートレース・競馬・競輪・パチンコ・ゲームなど）の成績 |
| **設定** | メンバー（名前・色・月の予算・給料日）、この端末の「わたし」、帳簿名、共有コード、エクスポート / インポート |

### ふたりで使う

- **メンバー**：帳簿にふたり（最大6人）を登録します。初回はサンプルの2人が入っているので、設定 → メンバー →「編集」で名前・色・予算を自分たちに合わせてください。
- **だれの**：明細を追加するとき「だれの」を選びます。初期値は「見ている人」→「この端末のわたし」の順。
- **この端末のわたし**：初回に「あなたはどちら？」と聞かれます（設定からいつでも変更可）。端末ごとに覚えるので、相手の端末では相手を選びます。
- **切り替え**：画面上部の「ふたり / 名前 / 名前」で集計の対象を切り替えます。「ふたり」は合算（予算も合計）、名前を選ぶとその人だけの収支・給料の使いみち・予算・ギャンブル成績になります。
- **予算と給料日は人ごと**：設定 → メンバー → 編集で、生活・遊び・ギャンブルの月予算と給料日をそれぞれ設定します。

### 明細の種類

- **生活**：家賃・食費・光熱費・通信費・日用品・交通費・保険/医療・サブスク など
- **遊び**：外食/飲み会・趣味・旅行・買い物・ゲーム課金 など（「遊んだお金」の管理）
- **ギャンブル**：**投入**（賭けた額）と**払戻**（戻った額）を記録。損益は自動計算
- **収入**：給料・ボーナス・副収入

### 集計の考え方

- **支出** = 生活 + 遊び + ギャンブルの投入、**収入** = 収入 + ギャンブルの払戻。**収支** = 収入 − 支出
- **給料の使いみち**：母数はその月の「給料・ボーナス」（なければ総収入）。「ふたり」ではふたりの給料の合計。ギャンブルは **純損失（投入 − 払戻）** で計上し、勝ち越した月は 0 として勝ち額を表示
- **ギャンブルの資金枠**：設定の「払戻を再投入できる」がオンなら、残り資金 = 枠 − 純損失（払戻は再び使える）。オフなら 枠 − 投入額
- 月の区切りはカレンダーの月（1日〜末日）

## ホーム画面に追加（インストール）

- **iPhone (Safari)**：共有ボタン →「ホーム画面に追加」
- **Android (Chrome)**：メニュー →「アプリをインストール」/「ホーム画面に追加」

## 共有のセットアップ（ふたりで同じ帳簿を使う）

既定では**この端末内のみ**にデータを保存します（ローカルモード）。`firebase-config.js` は `pms/` と同じ Firebase プロジェクトを使うので、**Realtime Database のルールに `money` の分を足す**だけで共有できます。

1. [Firebase コンソール](https://console.firebase.google.com/) → Realtime Database → **ルール** を次のようにして公開（`boards` は pms 用、`money` を追加）。

   ```json
   {
     "rules": {
       "boards": {
         "$code": { ".read": "auth != null", ".write": "auth != null" }
       },
       "money": {
         "$code": { ".read": "auth != null", ".write": "auth != null" }
       }
     }
   }
   ```

2. Authentication → Sign-in method → **匿名** が有効であることを確認（pms で設定済みなら不要）。
3. アプリの **設定 → 共有** で **共有コード**（例: `tomo-2026`）を入力して「接続」。バッジが「共有中」になれば成功です。
4. 相手には **共有リンクをコピー**（`?code=…` 付きURL）を送ります。相手がそのリンクを開くと同じ帳簿がリアルタイムで表示され、「あなたはどちら？」で自分を選べば、相手の端末からも明細を付けられます。
   - **閲覧専用リンク**（`&view=1`）は編集ボタンを隠した表示です。コードを知っている人は編集もできるので、閲覧だけにしたい相手にはこちらを送ってください（アクセス制御ではなく表示上の切り替えです）。
   - 明細には「だれの」の名前が色付きで表示されます。

別のプロジェクトを使う場合は `firebase-config.js` を差し替えてください（`pms/README.md`「クラウド同期のセットアップ」と同じ手順）。

## ファイル構成

| ファイル | 役割 |
| --- | --- |
| `index.html` / `styles.css` | 画面の骨組みとスタイル（白×ティール、丸ゴシック） |
| `app.js` | 描画とイベント（今月 / 履歴 / ギャンブル / 設定 / 明細シート） |
| `store.js` | データと集計の純粋ロジック（`deriveMonth` / `deriveGamble` / `deriveTrend` / `deriveMembers` など。メンバー・明細・予算） |
| `sync.js` | 共有コード単位のリアルタイム同期（Firebase / ローカル） |
| `firebase-config.js` | Firebase ウェブアプリ構成（公開情報） |
| `sw.js` / `manifest.webmanifest` | PWA（オフライン・ホーム画面追加） |
| `test-store.mjs` | 集計ロジックのテスト（77件）。`node money/test-store.mjs` |

## 動かし方

```bash
# リポジトリ直下で
python3 -m http.server 8000
# → http://localhost:8000/money/ を開く
```

## 注意

- 初回はサンプルデータ（2人分）が入っています。設定 → データ →「すべて削除」で明細を空にできます（メンバーは残るので名前を自分たちに変えてください）。
- 以前のバージョン（メンバー無し）のデータは、明細の「表示名」からメンバーを自動で起こして引き継ぎます。
- 共有コードは合言葉です。コードを知っている人は誰でも帳簿を見たり書いたりできるので、信頼できる相手とだけ共有してください。
- クラウド未設定でもすべての機能はローカルで使えます（共有のみ Firebase が必要）。
