# 📅 候補日メーカー — カレンダーの空きから、そのままメール

Googleカレンダーの**空き時間だけ**を読み取って打合せの候補日を自動で組み立て、
日本語のビジネスメール文面にしてGmail・メーラーへ渡すツールです。
候補を「仮押さえ」としてカレンダーに登録することもできます。

- 公開URL（GitHub Pages）: `https://ttomoi-afk.github.io/desktop-tutorial/schedule/`
- ビルド不要の静的アプリ（HTML / CSS / Vanilla JS のみ、サーバ不要）
- 予定の**中身（件名・出席者）は取得しません**。使うのは「埋まっている時間帯」だけです

## 使い方（5ステップ）

1. **カレンダーをつなぐ** … Googleでログインし、対象カレンダーにチェック（自分＋共有されている同僚のカレンダー）。
   まずは **「デモデータで試す」** で、接続なしに動きを確認できます。
2. **候補の出し方** … 所要時間・営業時間・昼休み・いつから何日先まで・前後のバッファ・提示数などを指定して「空きから候補日をつくる」。
3. **候補日を選ぶ** … 出てきた候補からチェックを外すとメールに載りません。足りなければ「もっと出す」。
4. **メールをつくる** … 宛先・会社名・宛名・用件・場所・署名を入れると、テンプレートに差し込まれてプレビューされます。
5. **送る** … 「Gmailで開く」「メーラーで開く」で**下書きが開く**ので、内容を確認してご自身で送信してください（自動送信はしません）。
   必要なら「選んだ候補を『仮』の予定として登録」で仮押さえもできます。

### 候補の決まり方

- 選んだカレンダーの予定（`freeBusy`）を取り、**前後のバッファ**を足した時間帯を避けます
- 営業時間内・昼休みの外・対象曜日のみ。日本の祝日は既定で除外（祝日カレンダーから取得）
- 「今から◯時間後」以降だけを候補にするので、送った直後の枠を提案してしまう事故が起きません
- 同じ日の候補どうしは重ならず、1日あたりの件数と合計件数の上限まで、早い順に選びます
- 「予定あり」でない予定（Googleカレンダーで**空き時間**扱いの予定）は埋まっているとみなしません

### 差し込みタグ

本文・件名・仮予定のタイトルで使えます。

`{{会社名}}` `{{宛名}}` `{{用件}}` `{{場所}}` `{{所要時間}}` `{{候補日}}` `{{回答期限}}` `{{差出人}}`

## セットアップ（Googleカレンダー接続）

デモモードだけなら設定は不要です。実際のカレンダーにつなぐには、**OAuth クライアントID**（ウェブアプリ）を1つ用意します。所要10分ほど・無料です。

1. [Google Cloud コンソール](https://console.cloud.google.com/) でプロジェクトを作成（既存でも可）。
2. **APIとサービス → ライブラリ** で **Google Calendar API** を有効化。
3. **APIとサービス → OAuth 同意画面** を設定。社内利用なら User Type は「内部」、
   一般アカウントなら「外部」を選び、**テストユーザー**に自分のGoogleアカウントを追加します。
   スコープは次の2つ（`.../auth/calendar.readonly`、仮押さえも使うなら `.../auth/calendar.events`）。
4. **認証情報 → 認証情報を作成 → OAuth クライアントID → ウェブアプリケーション**。
   **承認済みのJavaScript生成元**に、このページを開くURLのオリジンを登録します。
   - GitHub Pages: `https://ttomoi-afk.github.io`
   - ローカル確認用: `http://localhost:8000`
   （リダイレクトURIは不要です。トークンはポップアップで受け取ります）
5. 発行された `…apps.googleusercontent.com` を、
   - チーム全員で使うなら **`config.js` の `GOOGLE_CLIENT_ID`** に書いてコミット、
   - 自分だけで試すなら 画面の **「接続設定（クライアントID）」** に貼り付け（その端末にのみ保存）。

> クライアントIDは**クライアントに埋め込む前提の公開情報**で、秘密鍵ではありません（`pms/firebase-config.js` と同じ考え方）。
> 誰でも使えてしまうわけではなく、上記の「承認済みJavaScript生成元」と、利用者本人のGoogleログイン・同意で守られます。

### 同僚のカレンダーも見るには

相手のGoogleカレンダーの設定で、自分に **「予定の表示（時間枠のみ、非公開）」以上** を共有してもらうと、
接続後の一覧にそのカレンダーが現れ、チェックすれば空き時間の突き合わせに含められます。

## 動かし方（ローカル）

```bash
# リポジトリ直下で
python3 -m http.server 8000
# → http://localhost:8000/schedule/ を開く
# → 接続なしで試すなら http://localhost:8000/schedule/?demo=1
```

候補算出ロジックのテスト（依存なし・Nodeのみ）:

```bash
node schedule/test-slots.mjs
```

## ファイル構成

| ファイル | 役割 |
| --- | --- |
| `index.html` | 5ステップの画面 |
| `styles.css` | 白×グリーンの丸ゴシックUI（`pms/` と同じ系統） |
| `slots.js` | 候補日の算出と文面整形（純粋関数のみ・テスト対象） |
| `gcal.js` | Google認証・カレンダーAPI（`freeBusy` / カレンダー一覧 / 祝日 / 仮予定作成） |
| `app.js` | 画面の組み立て、保存・復元、メール下書きの受け渡し |
| `config.js` | OAuth クライアントID（公開情報） |
| `test-slots.mjs` | `slots.js` の自己テスト（21件） |

## 注意

- 設定・宛先・文面は**この端末（ブラウザ）のlocalStorage**にのみ保存されます。アクセストークンは保存しません（タブを閉じると失効）。
- タイムゾーンは**ブラウザの設定**をそのまま使います（日本で使う想定）。
- メールの送信は行いません。下書きを開くところまでで、送信は必ず人の確認を挟みます。
- 仮押さえは「非公開」の予定として登録します。取り消しはカレンダー側で削除してください。
