# NDA管理シート

秘密保持契約（NDA）の **企業名** と **締結日** を軸に、有効期限の状態までひと目で追える管理シートです。**Excelブック**（`NDA管理シート.xlsx`）と、同じ項目の **Webアプリ** の2つが入っています。どちらか使いやすいほうでどうぞ（CSVで行き来できます）。

## Excel版 — `NDA管理シート.xlsx`

3シート構成のブックです。数式・入力規則・条件付き書式まで設定済みで、開いてすぐ記入できます。

| シート | 内容 |
| --- | --- |
| `NDA一覧` | 企業名 / 締結日 / 有効期限 / 自動更新 / **状態**（数式）/ **残日数**（数式）/ 種別 / 目的・案件名 / 自社担当 / 先方窓口 / 原本の保管先 / 備考。151行目まで数式と書式を用意 |
| `集計` | 登録件数・取引先の社数・今年の締結件数・状態別・種別別の件数。「期限間近」とみなす残日数（既定90日）は黄色いセルで変更できます |
| `使い方` | 入力する列／触らない列、状態の意味、色の凡例、行の増やし方 |

- **状態は自動判定**：`有効` / `期限間近`（既定90日以内・オレンジ）/ `期限切れ`（赤）/ `自動更新`（青）/ `期限未設定`。行の色も状態に合わせて変わります。
- **入力の助け**：D列「自動更新」とG列「種別」はプルダウン、B・C列は日付以外を弾く入力規則つき。見出しにはコメントで説明を入れてあります。
- **すぐ使える**：ウィンドウ枠の固定・オートフィルタ・印刷設定（横向き / 幅1ページ / 見出し行の繰り返し）を設定済み。2〜3行目は記入例なので、行ごと削除してお使いください。
- 152行目以降に増やすときは、151行目をコピーして貼り付ければ数式と書式が引き継がれます（`集計`シートの参照範囲も広げてください）。
- Excelで「CSV UTF-8」として保存すれば、そのままWeb版に読み込めます。

## Web版 — `index.html`

ビルド不要の静的アプリ（HTML / CSS / Vanilla JS）で、`pms/`・`schedule/` と同じ白×グリーンの丸ゴシックUIです。

- 公開URL（GitHub Pages）: `https://ttomoi-afk.github.io/desktop-tutorial/nda/`
- データは **その端末のブラウザ（localStorage）にのみ保存**され、サーバーには送信されません。共有・移行は CSV / JSON の書き出しで行います。

## できること

- **一覧**：企業名 / 目的・案件名 / 締結日 / 有効期限（残日数つき）/ 状態 / 種別 / 自社担当。行をタップすると編集できます。
- **状態の自動判定**：`有効` / `期限間近`（残り90日以内・オレンジ）/ `期限切れ`（赤）/ `自動更新` / `期限未設定`。
- **サマリー**：NDA件数・取引先の社数・90日以内に期限が来る件数・期限切れ件数。
- **絞り込みと並び替え**：企業名・案件・担当・備考のキーワード検索、状態での絞り込み、締結日順 / 期限が近い順 / 企業名順。
- **入力の手間を減らす工夫**：締結日から「1年 / 2年 / 3年 / 5年」で有効期限を自動計算（締結日の1年後の前日、など）。企業名は登録済みの名前から補完。有効期限が締結日より前のときは保存しません。
- **CSV / JSON の書き出し・読み込み**、**印刷 / PDF 出力**（一覧をそのまま配布資料にできます）。
- キーボードショートカット：`N` で新規追加。

## 使い方

1. `nda/index.html` をブラウザで開く（GitHub Pages なら上記URL）。
2. **「＋ NDAを追加」** で、企業名と締結日を入力して保存。まず試すだけなら「データ」→ **サンプルを入れて試す**。
3. 期限を管理したい契約には **有効期限** を入れます。自動更新の契約は「自動更新あり」にチェック（期限欄は空のままで構いません）。
4. 定期的に **「期限間近」** タブを見て、更新・再締結の要否を確認します。

## 項目

| 項目 | 説明 |
| --- | --- |
| 企業名（必須） | 契約の相手方。集計の「取引先（社数）」はこの名前で数えます |
| 締結日（必須） | NDAを締結した日 |
| 有効期限 | 契約の満了日。空欄可（自動更新や期限の定めがない場合） |
| 自動更新 | 申し出がなければ延長される契約。状態は常に「自動更新」表示 |
| 種別 | 相互 / 当社が開示 / 先方が開示 |
| 目的・案件名 | 何のためのNDAか（企業名の下に小さく表示） |
| 自社担当 / 先方窓口 | 問い合わせ先 |
| 原本の保管先 | 共有ドライブのリンク、書庫の場所など |
| 備考 | 秘密保持期間、特記事項など |

## CSVの読み込み

1行目をヘッダーとして読み、**「企業名」列と「締結日」列が必須**です。次の見出しを自動で対応づけます（表記ゆれ・英語見出しも可）。

| 取り込み先 | 認識する見出し |
| --- | --- |
| 企業名 | 企業名 / 会社名 / 相手方 / 取引先 / company |
| 締結日 | 締結日 / 契約日 / 締結年月日 / 日付 / signedOn / date |
| 有効期限 | 有効期限 / 満了日 / 終了日 / 期限 / expiresOn / expiry |
| 自動更新 | 自動更新 / autoRenew（`○` `はい` `true` `1` などで有効） |
| 種別 | 種別 / 区分 / type（相互・当社・先方 の語で判定） |
| 目的・案件名 | 目的・案件名 / 目的 / 案件名 / 案件 / purpose |
| 自社担当 | 自社担当 / 担当 / 担当者 / owner |
| 先方窓口 | 先方窓口 / 先方担当 / counterpart |
| 原本の保管先 | 原本の保管先 / 保管先 / 原本 / URL / docUrl |
| 備考 | 備考 / メモ / note |

- 日付は `2025-04-01` `2025/4/1` `2025.4.1` `2025年4月1日` を解釈します（和暦は非対応）。
- **企業名と締結日が同じ行は同一のNDAとみなして上書き**します（重複登録を防ぎつつ、Excelで直した表をそのまま戻せます）。
- 企業名か締結日が読めない行は取り込まず、結果を「追加◯件 / 更新◯件 / 取り込めず◯件」と表示します。
- 書き出しCSVは **BOM付きUTF-8** なので、Excelでそのまま開けます。書き出しの対象は**画面に表示中（絞り込み後）の行**です。

## バックアップ・端末の移行

「データ」→ **JSONで書き出し** で全項目をそのまま保存できます。別の端末では **JSONを読み込み**（現在のデータを置き換え）で復元します。

## ファイル構成

| ファイル | 役割 |
| --- | --- |
| `NDA管理シート.xlsx` | Excel版（NDA一覧 / 集計 / 使い方 の3シート） |

## 注意

- Excel版とWeb版は自動では同期しません。両方使うときは、CSVの書き出し／読み込みでそろえてください（項目名は同じです）。
- Web版の保存先はブラウザです。**ブラウザのデータ消去や、シークレットウィンドウの終了で消えます**。大切な台帳は定期的に JSON で書き出してください。
- 端末内に契約情報が残ります。共用PCでの利用は避けるか、使用後に「すべて削除」してください。
- サンプルデータはダミーです。
